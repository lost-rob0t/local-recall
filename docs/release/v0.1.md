## Privacy invariant status at release

- **Capture state machine**: off-by-default, explicit start, hard capture gate; emergency stop and privacy mode halt persistence within tested bounds. Capture-off and stale-generation invariants are enforced in security tests.
- **Redaction**: deterministic, in-pipeline, before any provider; seeded-secret invariants prove plaintext never reaches storage, logs, bundles, or archives. Limitations (unknown patterns, region masking scope) are documented in [redaction](../redaction.md) and [troubleshooting](../troubleshooting.md).
- **Encryption**: envelope AEAD with key providers; tampering fails closed; quarantine + forward-only recovery for corruption.
- **Remote providers**: text and vision remote providers are fully supported behind explicit per-query `EgressAuthorization` + `EgressGate`; local is default; silent local→remote fallback is impossible (tested).
- **Local text models**: local embeddings + generation verified with deterministic providers and synthetic E2E flows; no provider hardcoding; real-model soak is a post-release validation item.
- **Remote text models**: authorized-remote path implemented and tested with the egress gate; no remote traffic can occur without a per-query grant.
- **Local vision**: redacted-frame-only analysis boundary (raw frames structurally rejected); mocked local providers verify the contract.
- **Remote vision**: requires a `REDACTED_IMAGE` egress grant bound to the exact provider; tested.
- **Audit**: sanitized counts/enums/digests only; content-shaped tokens are rejected by construction.

## Known limitations

1. **Daemon process mode** (`local-recall daemon`) is not implemented in v0.1: the CLI, IPC contract, UI server, health subsystem, and Nix module are complete, but no long-running server hosts them yet. The CLI fails closed with `daemon-unavailable` (exit 3). This is the blocker for closing #40's full VM lifecycle scenario and for end-to-end daemon-driven capture.
2. **Wayland capture** (#35, open): the portal backend, permission revocation, PNG codec, and busctl transport are implemented and tested against fakes plus live transport evidence; real-compositor validation on one wlroots compositor and one DE requires a human with a Wayland session.
3. **Real-model performance budgets** (8B-class local model soak, idle CPU, peak memory, OCR throughput) are defined in [e2e](../e2e.md) but must be re-measured on reference hardware before claiming them; CI enforces the synthetic-workload budgets.
4. **Redaction** is pattern/entropy-based; it cannot catch unknown secret formats (documented, policy-based exclusion of sensitive apps is the recommended control).
5. **Pykka-based lifecycle actor** runs threads inside the host process; the daemon process isolation story (separate system user + sandbox) lands with the daemon work.
