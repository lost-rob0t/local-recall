* Acceptance criteria
- Unlisted, writable-by-others, changed, malformed, or timed-out scripts are rejected.
- Captured window values cannot alter command arguments.
- Output is redacted and policy checked before use.
- Security tests cover command injection, path replacement, symlinks, oversized output, and hostile environment variables.

* Design decisions
- Closed typed config; absolute path; fixed argv via =create_subprocess_exec= (no shell, no interpolation); eager per-run script validation (regular file, no symlink, owner-only, current owner, optional SHA-256 pin).
- Strict versioned JSON output schema with closed keys and bounded values; everything else fails sanitized.
- Environment allowlist and fresh private working directory per run; stdin closed; stderr discarded; timeout/output-limit violations kill the child.
- Provenance uses the adapter name and a digest-derived adapter revision so downstream redaction/policy handling treats script output identically to other metadata sources.
- Degradation: adapter failures are sanitized exceptions; metadata absence never expands capture permissions, and capture policy remains deny-by-default for sensitive contexts.
