* Acceptance criteria
- A supported local VLM can enrich synthetic records without network access.
- Provider unavailability does not block normal OCR-based capture.
- Outputs are schema validated and linked to the exact source record and model version.
- Tests prove unredacted frame types cannot be passed to the vision provider.

* Design decisions
- Single provider abstraction (existing =ModelCapability.VISION= + =supports_vision=) serves local and remote providers; remote execution additionally requires the existing =EgressGate= with a per-query =EgressAuthorization= bound to the provider and granting =REDACTED_IMAGE=. No silent local-to-remote fallback exists; without a grant remote analysis is refused.
- The request boundary structurally accepts only =RedactedFrame=; raw frames are rejected at construction and re-checked in every service entry point (including tampered request objects).
- Output is a closed dataclass schema (record link, provider, model version, visible application state, document type, broad task, uncertainty). No identity/biometric/personal-attribute/hidden-content fields exist; the boundary rejects malformed values.
- Image input budget fails closed; =enrich_optional= makes provider unavailability a non-blocking best-effort so OCR-based capture continues.
