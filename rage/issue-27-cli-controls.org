* Acceptance criteria
- Control commands are idempotent and return meaningful exit codes.
- =stop= confirms that capture and pending persistence have ceased.
- =ask "What was I doing Saturday?"= produces cited output.
- Tests cover unavailable daemon, locked key store, and concurrent control requests.

* Required command surface
- =start=, =pause=, =resume=, =stop=, =status=
- =privacy-on=, =privacy-off=
- =ask=, =timeline=, =search= with explicit time filters
- =config validate=, =providers=, =health=, =storage stats=
- Machine-readable JSON where useful.

* Hard invariants
- The CLI must not become a second lifecycle, policy, retrieval, or provider authority.
- Stop/privacy control must remain higher priority than ordinary query work.
- CLI/status/error/completion surfaces must not expose captured text, raw OCR, titles, command lines, secrets, provider payloads, or storage paths.
- No plaintext capture artifacts or temporary screenshot files.
- Local-first routing and no silent remote fallback remain authoritative.
- Tests and CI must remain failure-honest; zero required tests is failure and no false-green constructs are permitted.
